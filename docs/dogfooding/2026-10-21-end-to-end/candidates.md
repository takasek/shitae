## 除外したもの

- **仕様上の意図した制約**: 全 source bytes と engine の一致要求による MODEL_MISMATCH、表示設定が保存対象外、GUI で画面外の部品の値を一覧しないこと（ADR-0025）、自由文 effect が履歴にだけ出ること。
- **評価環境の制約**: Claude in Chrome の注入失敗、built-in browser でのファイル選択・保存ダイアログ（利用者が操作）。製品の問題と断定しない。
- **モデルの誤り**: 今回の保存済みモデルに新たな誤りは見つけていない。作成担当 v1 の予約状態の寿命は、要件を操作で具体化した結果で、v2 で直した。
- **処理系の不具合・回帰**: 診断の疑い（上表 2 行目）以外は、今回の操作で見つけていない。全境界の不具合不存在という意味ではない。
