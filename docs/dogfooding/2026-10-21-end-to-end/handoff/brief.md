# 引継ぎ資料

2 つの文書（A・B）を並べて編集するエディタの UI フロー案を shitae で検討した。作業の途中を保存したので、続きを引き継いでほしい。

検討していた問い:

- 文書A を保存しようとしてディスク側の変更に気づいたとき、比較画面での選択によって A の保存状態と画面はどうなるか。
- 文書B の未保存の編集は、A 側の操作の間どう残るか。

渡すもの: 生成 HTML（astra-proposed.html）、操作の再生ファイル（astra-ghost-branched.scenario.json）、定義（model/proposed.shitae）、処理系の版（version.txt）。
