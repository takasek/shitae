# 人向け受取評価の実施段階

## 状態

2026-10-23：利用者が人による受取評価をまだ行わず、AI用の評価を進めると指示したため、以下の全段階は保留。人の回答をこれ以上求めず、画面と一時配信は終了した。開始画面の準備を評価成功に数えない。初見AI評価は別記録へ分ける。

見学予約v2のHTMLと対応する9 dispatchのscenarioを、新しいGUIに読み込んだ。AIは読込だけを補助した。人の説明・次の操作・保存は未実施のまま保留。元モデルや作者のreport・補助scriptは追加提示していない。利用者は前段の評価概要を読んでいるため、完全な初見とはしない。

## 段階と判定

| 段階 | 提示物と課題 | 現在 |
| --- | --- | --- |
| 1 読取 | HTML・scenarioだけから経緯、現在の状態、選んだ条件を説明する。分からない点もそのまま記録 | 質問提示後、利用者判断で保留 |
| 2 継続 | 人が次に確かめたい操作を一つ実行し、GUIで再保存する。回収した実ファイルで選択と再生を確認 | 未実施・保留 |
| 3 編集・再検討 | 1・2の後に元モデル一式・版・必要な設定を提示し、再生成、一箇所の要件変更、旧記録拒否、新規記録を人が判断する | 未開始・保留 |
| 4 途中分岐の説明 | 作者の答えを先に示さず別の分岐記録を読んでもらい、その後に分岐理由を添えた資料を提示する | 未開始・保留。単純な見学予約の記録を途中分岐の効果確認へ流用しない |
| CLI負担 | cli-task.md。人が端末でhandleを再取得・転記する手間を確認 | 準備のみ・保留 |

人の発言を根拠に、理解できた範囲・迷い・追加質問を記録する。AIが代行して達成済みにしない。同じ人への段階的な説明の前後だけで、一般の人への改善効果を断定しない。

人向けのブラウザーとlocalhost配信は終了済み。再開は利用者の指示時に行う。
