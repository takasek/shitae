# 備品貸出の検討引継ぎ

問いは、確認中の受取選択を取消で捨てられるか、確定した依頼が一覧と詳細を開き直しても残るか。対象は固定の「会議用プロジェクター」1件。同じ実行内の状態保持を検討し、実際の貸出通信、任意件数の在庫管理、ディスクへの永続保存は対象外。

初期状態は備品一覧、依頼状況は未依頼、確認の作業は未開始。v1の新規確認の初期値は窓口。v2は社内推奨受取方法の変更により初期値だけをロッカーにした。両版の取消では詳細へ戻って未依頼を保ち、新しく開く確認はその版の初期値になることを期待する。確定後は詳細・一覧の両方で確定した受取方法が見えることを期待する。取消や受取選択だけで確定依頼を作らないことが不変条件。
