# 科学館の見学予約を引き継ぐ

問い：確認中の案内方法は取消で捨て、確定した予約は画面を開き直しても保持する設計でよいか。v2では確定通知を追加した。通知を消しても予約済は残るべき。

初期状態は施設一覧・未予約・確認作業なし・通知なし。固定の代表施設一件を扱う。案内方法は確認画面の状態、予約済は同じ実行内の共有状態。実際の予約送信・永続保存・施設IDごとの管理は対象外。

両版ともimport・simconfigなし。処理系commitは shitae-revision.txt。元モデルの入口名とbytesを保持して同版で再生する。旧版scenarioをv2へ読み込むと MODEL_MISMATCH が期待される。修正版は初期状態から検討して新しい記録を作る。

確認したい不変条件：取消で予約は未予約のまま、再入場した確認は現地案内。確定で確認が閉じ、一覧と詳細の予約済が残る。v2の通知の寿命は予約済と独立。
