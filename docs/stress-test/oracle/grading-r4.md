## 所見

- **Q2 が唯一の乖離で最重要**。被験者は「モジュール同一性＝ファイル」「`::` の解決は書かれたファイルの import 表」（ADR-0017 転記文）から「無修飾の裸参照も書かれたファイル基準」と外挿——内部整合レビュー §5 の「①が妥当な類推」と同じ読み。実装は発火時のアクティブフレーム module（②）で、掲示中 overlay の無修飾 set は黙って no-op。**M2 実測・内部整合レビュー・オラクル被験者の 3 経路が独立に同一座標へ収束**（r3 B1 の singleton モジュール境界と同型の「`::` 原則からの外挿を実装が裏切る」構図）。
- 確信度較正は良好: 高確信度 5 問は全問正解、不正解の Q2 は中に割り引かれていた（「一文で明言した記述が無い」の申告つき）。r3 で問題化した「確信度高の乖離」は r4 焦点構文ではゼロ。
- Q1 の申告「@S の対象が現在フレーム自身という自己参照ケースの明示記述なし」・Q7 の申告「error 診断検出後の実行時扱い（継続 vs 拒否）の一般規則がない」は D 候補。
- R005 のアクティブパス限定・exit の LIFO 走査（Q4/Q5）は SPEC 本文だけから正しく導出可能と実証——ADR-0016 の転記品質を裏づけ。
