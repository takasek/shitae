# frame 意味論オラクル r4 — 予測課題

以下の各設問について、遷移列を実行した後の状態を予測せよ。前提: エントリポイントは `ホーム`（module 修飾なしのエントリファイル）。`#!` と注記された component は singleton。各設問は独立（状態を持ち越さない）。

回答フォーマット（設問ごと）:
- 予測: アクティブ画面（component##variant）・共有レジストリの内容・警告の有無（コード名まで分かれば）・設問が聞いているその他の値
- 根拠: 参照した SPEC の節
- 確信度: 高 / 中 / 低（SPEC から決められないと思うなら「決められない」と明記し、どの記述が足りないかを書く）

## Q1

```
push(確認, @co)
switch(別枝, @co)
```

switch 実行後のアクティブ画面はどれか。`別枝` は開かれるか。

## Q2

モジュール `mod`（別ファイル）に singleton `#! 状態`（variant: 再生 / 停止）と component `ミニ` が定義されている。`ミニ` の body には `> タップ(停止ボタン) -> set(状態##停止)` がある（`mod::` 修飾なしの裸参照であることに注意）。

エントリファイルの `ホーム` から:

```
show(mod::ミニ)          // ミニを掲示
（ホームがアクティブなまま、掲示中のミニの「タップ(停止ボタン)」を発火）
```

発火後、共有レジストリの (mod, 状態) は 停止 に書き換わるか。

## Q3

`#! 学習`（variant: 通常 / ハート切れ。initial は 通常）。

```
set(学習##ハート切れ)
push(学習)
```

push 後の学習画面はどの variant で開くか。

## Q4

```
push(確認, @co)
present(モーダル)        // 無名 present（barrier あり）
push(支払い, @co)
```

3 手目で警告（R005）は出るか。

## Q5

```
switch(タブA, @a)
switch(タブB, @b)
push(X, @a)              // タブB の中で、タブA と同名の @a を begin
exit(@a)
```

(i) 3 手目 `push(X, @a)` で R005 警告は出るか。(ii) `exit(@a)` 後のアクティブ画面はどれか（タブA と タブB のどちらの @a が畳まれるか）。

## Q6

`#! 学習`（variant: 通常 / ハート切れ）。

```
show(学習)               // 掲示（variant 省略）
set(学習##ハート切れ)
```

set 後、掲示中の 学習 の表示 variant は何か。

## Q7

`# 記事`（通常 component・非 singleton。variant: 一覧 / 展開）。

```
set(記事##展開)
```

runtime で何が起きるか（アクティブ画面・共有レジストリ・エラー/警告）。
