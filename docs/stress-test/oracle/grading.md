## 所見

- **Q3 が最重要**: SPEC の字義（「セッションは遷移に紐つく」「begin した地点へ戻る」）を素直に読むと exit は効くと読める。実装は goto でフレームを全置換して begin マーカーを消す。spec を実装に合わせる（「goto は現在フレームの begin マーカーを破壊する」と明記）か、実装を読者期待に合わせる（begin をフレームでなく位置に紐づけ goto 後も保持）かの設計判断が要る。読者期待は後者。
- Q2・Q4 で被験者が「SPEC だけでは決められない」と正確に申告できた — 曖昧箇所の座標として S14・S6 と完全一致。手トレース（Phase 1）と独立手法で同じ穴に到達しており、確度が高い。
