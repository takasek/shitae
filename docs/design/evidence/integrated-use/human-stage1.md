# 人の受取評価：段階1

対象は経費申請の審査フローです。固定処理系 `278103a97da5319e8f97bb3218d6508b7cfd2a8d3ebd479aed3faf00f75f5116` で生成した HTML と、同じモデルの探索記録を渡します。処理系を知る設計者による受取として記録します。

目的・問い：審査確認で各判断を選ぶと、どの結果がまとめて生じるか。審査中に領収書の照合結果が変わった場合、現在画面・承認状況・照合状況・通知を区別して説明できるか。確認画面と通知から開くコメント画面の終了はどう表されるか。

## お願いする操作

1. 渡された HTML を開き、scenario を「シナリオを読み込む」で読み込んでください。scenario の JSON 本文、モデル本文、この directory の他の評価資料はまだ読まないでください。製品の表示や検討手順は参照できます。
2. 表示から、操作と選択条件の順序、現在地までの経路、巻戻し先と捨てた結果、保存に含まれるものと含まれないものを説明してください。読み取れないところは推測せず、そのまま教えてください。
3. 元の問いを確かめるため次に適切と思う一操作を行い、「シナリオを保存」で再保存してください。ファイルの場所と、選んだ操作・条件を教えてください。
4. 説明に必要だった追加質問、操作/条件の選び間違いと修正、製品値の手入力や転記があれば教えてください。なければ「なし」で十分です。モデルを読んでいた場合も申告してください。

説明と保存物を確定してから、次の段階で全モデルと変更要件を渡します。速度比較は行いません。
