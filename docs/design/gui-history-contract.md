# GUI の履歴閲覧・再開・状態確認

[ADR-0025](../adr/0025-history-preview-and-resume.md) に基づく生成HTMLの表示契約。言語構文やSessionの実行・保存契約は変更しない。

## 閲覧と再開

「操作を続ける位置」は次の操作の開始点で、記録番号・操作・選んだ条件・結果内の状態・画面を常時表示する。「見ている履歴の画面」は表示専用selectionであり、Session世代とobservation IDで識別する。閲覧・展開・表示設定・取消・閲覧終了によってstate/revision/journal/export/現在の操作handleを変更しない。

記録見出しは詳細の開閉だけを行う。dispatch、seek、reset、手動試験を区別し、journal stepをそのまま記録番号に使う。結果は選択後に実行された順であり、択一候補ではない。結果内の複数点には結果番号と状態番号を付ける。「画面を見る」はqueryだけを使い、当時の包含・overlay・共有値とhandleなしactionsを説明として描く。過去画面には実行controlを結び付けない。

「履歴の閲覧を終える」は現在の操作画面を表示し、操作位置を変えない。「この時点から続ける…」は確認を開き、変更前・変更後の記録・操作・条件・結果・状態・画面を示す。「位置の変更をやめる」は位置を変えず直前の表示へ戻る。確定時だけseekし、閲覧を解除する。同じ点への再開は無効とし理由を示す。確認直前の世代・revision・seekableと一致しなければ移動せず、選び直しを案内する。

再開は当時の操作や未消化resultの自動実行を意味しない。seekだけでは後の保持点を破棄せず、後の点も閲覧・再開できる。新たな観測点を作る操作が後続点を破棄すると文章のみになる。無観測no-opや拒否では保持する。画面の見た目が同じかどうかを観測生成の判断にしない。

| 状態 | 表示と操作 |
| --- | --- |
| current | 現在の操作位置。閲覧可、同一点への再開は無効 |
| retained | 閲覧・再開可 |
| ghost | 後の履歴・閲覧・再開可 |
| discarded/reset前 | 文章のみ。画面は残っていないと説明、閲覧・再開不可 |
| 観測なしの結果 | 再開できる地点なし。隣の点を割り当てない |
| 一記録内で保持・破棄が混在 | 一部の結果は文章のみ。各点の可否を個別表示 |

「この操作の最後に保存された状態を見る」はcompletionObservationIdを対象とする。最終結果が無観測なら前の結果に属することがあり、実際の結果・状態番号を示す。全結果無観測の場合は近道を作らない。host/配置/厳密ID/観測点一覧は技術詳細にまとめる。

## 表示の寿命と位置

受理した実行commandはno-opを含め閲覧と確認を解除する。閲覧対象が破棄されたら文章は残ると通知する。拒否は状態と閲覧を保持しエラー表示する。resetと成功loadでは世代を更新する。load失敗は旧Sessionと閲覧を維持し、新Sessionの一部を混ぜない。閲覧対象が無効と判明したら古い表示・再開入口を消し、理由を示す。別点の閲覧は前のselectionを置換する。

履歴の行ID・画面内offset・focusを保存し、展開や表示切替で読取位置を保つ。点が折畳み/filterで消える場合は親の記録見出しの変更前offsetへ復帰する。filter controlのfocusは維持する。表示設定だけでは閲覧selectionを解除しない。先頭での履歴追加は新記録へ追従し、中段では位置を保ち新しい記録を通知する。load/resetでanchorが失われたら新しい現在地を示す。

右側のスクロールは現在表示と各閲覧対象で別々に保持し、新対象の初回は先頭へ移す。focus復元はscrollを強制しない。選択行と現在の操作位置は文字と枠で区別する。狭幅は一列とし、閲覧終了と現在位置の入口を残す。表示状態はscenarioに含めない。

## 読込要約と画面外の状態

「読み込んだ時点の状態（一部）」はmain/overlayのroot・包含・member gateが参照するsingletonをrootごとに重複排除したもの。全業務データでも全singleton一覧でもない。0件でも画面外に存在しないと推論しない。1〜5件は直接表示、6件以上は表示箇所別件数と折畳み一覧とする。異moduleの同名部品はmoduleを添える。

成功通知直下に要約・範囲説明・「画面外も含めて状態を確認する方法」を表示する。実行command時に要約を消す寿命は維持する。継続後も「定義と実行プログラムの版・再現用の資料」の直後に同じ案内入口を常時表示する。版情報を開かなくても見つけられるようにする。

読込時点には元のファイル、現在の状態には「操作の再生ファイルを保存」の出力を使う。履歴閲覧中でも保存対象は操作を続ける位置。対応する定義の入口とimport一式、完全なmodelId/engineVersion、実行プログラムを揃え、CLI session --replayを起動して同じprocessへ `{"id":"shared","command":"query","select":["state"]}` を送る。応答のdata.state.sharedVariantsをmodule/componentで識別して読む。HTMLだけで定義本文を取り出せるとは案内しない。資料がなければ作成者へ求め、照合失敗をscenario編集で回避しない。

## 検証

不変性・同一点・複数点・無観測末尾・保持/破棄混在・失効確認・reset/load/拒否/no-opを機械検証する。実ブラウザーで履歴anchorの通常2 CSS px以内の保持、focus、狭幅、表示切替、再開を確認し、端のclampは区別して記録する。AI利用レビューを独立agentで実施する。人による利用評価は今回の実装完了の待機条件にしない。
