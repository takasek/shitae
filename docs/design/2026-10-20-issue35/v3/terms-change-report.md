# v3.2 表示用語の反映

[統一用語](terminology.md)をA/B/C設計書、UIの固定・動的表示、状態通知、資料案内へ反映。旧版は親のreview/source-v3.1-before-termsに保存。過去の試行・レビュー・候補表は当時の証拠として残す。

- 閲覧：画面表示のみ。「履歴の閲覧を終える」で操作を続ける画面を表示し、位置は変えない。
- 再開：「この時点から続ける…」で確認し、「この時点から続ける」で位置を変更。「位置の変更をやめる」は位置を変えず履歴の画面を再び表示。
- 申請内の移動：「前の画面へ（申請の操作）」。履歴閲覧の終了とは別の操作であると補足。
- 結果件数は「結果 N件」、位置は「結果Nの直後」。条件ラベルがない場合は「選んだ条件：なし」。
- モデル・シナリオ・処理系には「画面と操作の定義」「操作の再生ファイル」「実行プログラム」を併記。正式キーと元の行動名は維持。
