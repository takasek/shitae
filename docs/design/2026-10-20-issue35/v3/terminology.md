# 設計案の統一用語 v3.2

ユーザーの依頼により、用語提案を現行設計案へ反映した。画面・設計書・資料案内はこの表を正とする。旧試行の引用と証拠、モデルの行動名、JSONキー、API名は改名しない。製品・言語仕様の変更は行わない。

| 概念・場面 | 統一表記 | 説明・境界 |
| --- | --- | --- |
| 次の操作の開始点 | 操作を続ける位置 | 記録・結果番号を添える。スクロール位置と区別 |
| 一覧の現在位置ラベル | 現在の操作位置 | 押すボタンと同じ命令形にしない |
| 履歴の表示対象 | 見ている履歴の画面 | 現在の操作位置より後の履歴も含む |
| 履歴を見ること | 閲覧 | 表示だけを切り替え、操作を続ける位置は変えない |
| 閲覧の終了 | 履歴の閲覧を終える | 操作を続ける画面を表示する。位置は変えない |
| 開始点を変えること | 再開 | 操作を続ける位置の変更。申請操作や未消化結果の自動実行ではない |
| 再開の入口 | この時点から続ける… | 確認を開く |
| 再開の確定 | この時点から続ける | 確認に示した位置へ変更する |
| 再開の取消 | 位置の変更をやめる | 位置を変えず、見ていた履歴の画面を再び表示する |
| 画面を保持している履歴 | 閲覧・再開可 | 両方の可否を明記。後続は「後の履歴・閲覧・再開可」 |
| 画面が残っていない履歴 | 文章のみ | 操作・条件・結果は読めるが、画面は閲覧・再開不可 |
| 観測点の利用者向け説明 | 再開できる地点 | 結果の途中も含む保存された状態。正式語「観測点」は技術説明に残す |
| 観測点のない結果 | 再開できる地点なし | 結果単位の説明。操作全体に点がない場合だけ「再開できる地点を作らなかった操作」と呼ぶ |
| 申請画面内の移動例 | 前の画面へ（申請の操作） | 履歴閲覧の終了とは別。定義内の行動名は「前の画面に戻る」のまま |
| 結果件数・位置 | 結果 N件／結果Nの直後 | この操作で起きたことを順に示す。択一の結果候補ではない |
| 条件ラベル | 選んだ条件：ラベル／なし | 「なし」は条件ラベルがないこと。入力漏れ・自動判定・presence gateと混同しない |
| 共通になる部品の状態 | 部品の共有状態 | 同じ部品を別の場所で使うときも共通になる状態。全業務データではない |
| 読み込み時の一部状態 | 読み込んだ時点の状態（一部） | 対象範囲を併記。現在値と一致する場合もある |
| モデル | 画面と操作の定義（モデル） | 画面だけの定義に縮めない |
| シナリオ | 操作の再生ファイル（シナリオ） | 自然文の利用シナリオと区別 |
| 処理系 | 実行プログラム（shitae） | 同じ版を使う |
| modelId／engineVersion | 定義の識別子／実行版の識別子 | 正式キーを併記し完全一致で照合 |
| module／component／variant | 所属／部品／選ばれている状態 | JSONキーは維持。所属と部品の組で特定 |
| seek | 操作を続ける位置の変更 | 通常説明にAPI名だけを突然出さない |

「戻る」を単独の履歴操作名には使わない。申請画面の移動先、スクロール位置の復元、保存資料内の元の行動名を述べる場合だけ対象を明記する。「後の履歴へ戻れる」は「画面を閲覧したり、その時点から再開したりできる」にする。

この反映は表示・説明の整理であり、比較差分の新機能や履歴行の追加、任意の時点の保存、模型の未表現要件を実装するものではない。旧用語案と初見評価は過去の記録として残す。
