## 修正と検証

独立実装レビューの初回指摘3件（focus、近道の番号、metadataなしの起動誤表示）を修正し、再レビューで解消した。ブラウザー試行で通知高さ変化によるviewportずれを再現し、相対座標からviewport絶対座標へ変更。条件候補なしは「なし」、その記録が破棄した地点数は記録自身の状態数と区別する。

TDDログはevidenceの `*-red.log` と `*-green.log`。新規製品テスト9件。全packageの最新結果を合わせて794件成功（変更のない7packageはfulltest2、変更対象simulator257件・CLI36件はdeliveryログ）。build・typecheck・diff-check成功。末尾の表示文修正は関連17件を再実行し成功。設計デモの既存4件も成功。長い履歴の近道ラベルは既知stepを使い、30操作の描画で495回あったdetail照会の二重走査を除いた。
