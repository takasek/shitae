# 設計案 v3.1

前回のAI利用試行を受けた説明・具体データ・再現資料の改訂。製品・SPEC・共通ガイドは変更しない。

[単体表示用UI](standalone-preview.html) / [検証用UI](ui-proposal.html) / [資料と確認手順](materials/guide.html)。旧版は親ディレクトリのui-proposal.htmlに保存。v1/v2のモデルと試行証拠は変更しない。

## 変更

- 参照帯は「当時の画面内の操作」を実行できないと明記。戻る・続ける操作と区別。
- 現在位置は「操作を続ける位置」、参照先は「見ている時点」と説明。正式な用語変更は再試行の提案を得て判断。
- 再開後も後続へ戻れること、新しい観測点が作られると後続snapshotを失うこと、文章は残ることを説明。見た目が変わらない操作全般をno-opとは呼ばない。
- 全行同じ架空データを、固定代表申請の12操作に置換。金額訂正・差し戻し・再申請・承認・支払いを比較できる。
- 各表示値は公開CLIで保存したscenarioをSessionの読取APIで抽出。模型内の移動は表示デモ。対応する実seek・分岐は別途生成したscenarioに記録し再生確認。
- 画面外の文書Bは表示要約に含めず、対応モデル・読込/再開/無移動/分岐scenario・処理系の場所と版を案内する。
- 観測点のない操作例は戻り先のないback()。hide(未掲示)はこの処理系で観測点を作ったため採用しなかった。

## 検証の境界

比較と分岐ロジックはscripts/state.test.mjs（Red/Greenをevidenceに保存）。generatorは実際の状態値と別Session再生を検査。業務の送信・支払い・ファイル保存は行わない。AI試行を人の受入に換算しない。

## 独立レビュー後の修正

v3初版はusability/input-v3へ固定保存し、初見試行中は変更しなかった。v3.1は無観測no-op受理後の参照解除、実行後の古い確認欄の解除、位置と履歴に対応する資料だけを案内する処理を修正。初版のテストは参照保持を誤って期待していたため、既存契約に合わせて訂正した。再レビューと対象4テストが通過した。

利用試行はusability/report.md、用語案はterminology-proposals.mdを参照。単体表示用HTMLはscripts/build-preview.mjsで検証用UIから生成する。直接編集しない。

## 限定模型の省略

任意時点のシナリオ保存、結果内の複数観測点の表示、同一点への再開無効化、参照対象ごとのスクロール保存、参照中の行の標示、新操作の履歴一覧への追記は製品実装を表現していない。分岐操作の試行は記録7結果1からの一回に限定。分岐後に別位置へ戻った場合の資料は未用意と案内する。これらはA/Bの受入条件の撤回ではない。
