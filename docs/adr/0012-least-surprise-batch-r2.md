# ADR-0012: round-2 驚き最小バッチ — 未規定・小物の一括確定

- Status: accepted（2026-07-12、設計者一括承認。個別判断を要した 5 件は ADR-0007〜0011）
- 出典: stress-test r2 findings B3/B7/B8/B9・C2 以降・A 系の仕様側確定

## Decision（各 1 行。番号は findings-2026-07-r2.md）

- **B3** `back(X)` は barrier なしフレーム境界を**越えて**アクティブパスを遡り、**越えた子フレームは begin マーカーごと破棄**される（barrier では停止 = ADR-0001 不変）。verb 対応表の「同じ F」を訂正。
- **B7(a)** presence gate の裸参照で host component が存在しない（document common）場合は**判定不能 → always-on**（既存フォールバックの明示的拡張）。
- **B7(b)** document common の実行時スコープは**アクティブ画面が属するファイル**のもの（SPEC の「そのファイルの」の字義どおり。エントリファイル固定の simulator 実装は修正対象）。
- **B8** 同名 @S の解決は exit/dismiss（アクティブパス LIFO 優先 → 遠隔は最新）と switch 復帰（木全体で最新のみ）で**非対称** — 意図的である旨を一言明記。
- **B9** 前方参照は document common に限らず**一般に可**（参照は定義順と無関係）を総則化 / 全角括弧 `（）` は free-text の一部（構造記号は半角のみ） / E001（`> -> R`: 行動が空）と E012（1 行に `->` 2 つ）の区別例を診断表に付す / 対応表の孤立参照「（B2）」を除去 / エントリポイント表現ゆれ統一 / 外部イベント（配達完了・セッション切れ等）を行動の自然文として書くのは想定内と明文化 / 未定義 variant への `goto(##X)` に lint（W105）。
- **記号の name 混入の施行**（round-2 A10/A11 の仕様側）: overlay 引数への `*` は**構文エラー**（E024）/ 要素行の参照末尾 `?` は**構文エラー**（E025、gate は行動対象専用）/ 空の対象参照 `行動()` は**構文エラー**（E026）/ condition label 風 `[...]` で始まる要素名は**警告**（W104）。
- **C2** root への収束記法（`back(@R)` 等）は導入しない。保持系 `switch(タブ, @S) ; push(先)` と破棄系 `exit(@S) ; push(先)` の 2 慣用句を SPEC に例示。
- **C3/C5/C6** タブバー部品化（switch 群を部品に置き各画面は要素を置くだけ）・システム戻るジェスチャは自然文の行動・タブ再タップで底へ戻す慣用句 — いずれも**既存仕様の例示のみ**で対応（新記法なし）。
- **C4/C7** 条件付き要素・インスタンス向け外部イベントは**導入しない**（variant 分割か自然文注記が正攻法、を明文化）。

## Consequences

SPEC 改訂 2 pass（意味論 / 小物）に反映し、parser（E022〜E026・W104）・resolver（空白畳み込みは ADR-0006 B6 の既定どおり実装追随）・runtime・simulator を TDD で追随。診断コード表に新コードを追記。個別の証拠は findings-2026-07-r2.md と probes/oracle の採点記録を参照。
