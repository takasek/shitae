# ADR-0024: simulator 観測 UI の第 2 イテレーション — 実機評価駆動の再設計

- Status: accepted（2026-07-20、設計者確定）
- 出典: Playwright + Chrome の実機 UX 評価 2 回（.superpowers/sdd/ux-eval-report.md / ux-eval-round2.md 相当の実機観察）と設計者フィードバック。本 ADR は ADR-0022 のレイアウト節・遷移マップ描画方式と ADR-0023 の一部表示規則を supersede する

## 検収プロセスの確定

UI 生成物の検収は diff レビューだけでなく、subagent が実際に Chrome を駆動（Playwright + ローカル Chrome、スクリーンショット目視込み）して使用感を評価する実機評価を併用する。第 1 回評価は diff レビュー全通過後の成果物から Critical 3 件（埋め込み部品の操作不能・無名 dismiss() の root 崩壊・hover 無限フリッカ）を検出した — vm テストと文字列アサーションでは実ブラウザの破綻を検出できない。

## レイアウト（ADR-0022 の 3 ペイン構成を置換）

全幅 2 カラム。左 = 統合ログ専用。中央 = 現在の画面 → スタック → 遷移マップの縦 3 領域（ミクロ → マクロの順。スタック・マップは折畳み可・開閉状態保持）。gate 観測は常設第 3 カラムをやめトグルで開くドロワーへ（空き幅は中央へ還元）。

- 理由: スタックとログを同一カラムに縦積みすると伸長時に食い合う。gate パネルは大半の文書でほぼ空のまま幅 20% を占有していた（実機評価の実測）

## 統合ログの表示規則（ADR-0023 を拡張）

- newest-on-top（新しいエントリが上）。配列・cursor・ghost の意味論は変えず描画順のみ逆転
- 各エントリに記録時のアクティブ画面名を薄いラベルで併記する — effect 等のイベント行が前後の遷移行を見ずに単独で文脈を持つため
- back は物理ボタン・画面内操作とも通常の遷移としてログに積む（ADR-0022 の「末尾除去」を置換。undo はログのエントリタップ = cursor 巻き戻しに一本化）

## 画面カードの表現

- アクション行は「押せるもの」と分かるボタン様の見た目にし、静的な表示要素と視覚区別する。ラベル無し操作は行全体がボタン（[TRUE] チップ表記は廃止）
- document common 由来の操作は「外部イベントを発生させる」折畳みセクション（既定閉）へ分離 — 主操作（component/variant/部品由来）と視覚優先度を分ける
- 有効範囲は scope バッジ（説明 tooltip 付き）で明示
- アクション表示全体をチェックボックスでオフにできる（構造だけを見たい局面向け）
- member gate 付きの操作は gate off でも「無効」表示で残し、行内で対象 variant をその場切替できる（off で行ごと消えると存在に気づけない）。host gate（裸 gate）off は従来どおり除外 — 要素がその variant に構造的に存在しないため

## 遷移マップ（ADR-0022 の描画方式を置換）

- rank 割当は BFS 最短路から **longest-path**（dot 本来の方式）へ — BFS では大半のノードが rank 1 に落ちて縦積みになる。遷移チェーンは横並びが基本
- **モジュール別スイムレーン**: module ごとの水平レーンに分けてレーン内で個別レイアウト。cross-module エッジはレーンをまたぐ
- **固定ノードサイズ + スクロール**: viewBox 全体縮小を廃止。ノードは可読サイズ固定、収まらない分はマップ領域内スクロール（18 ノードで 12px 級まで潰れた実測への対処）
- **近傍表示デフォルト**: 既定は現在地から 2 ホップの近傍のみ。「全体を見る」トグルで全ノード
- **tooltip**: hover 情報は上部固定領域でなくノード近傍の絶対配置 tooltip（レイアウト非干渉）。ノードタップで固定（pin）し、粒度メニュー（variant 分割/統合）と gate 試験の variant 切替を内包。「遷移関係は閲覧専用・表示粒度は操作可」を説明文で書き分ける

## gate 試験の 3 面展開

同一の共有レジストリ（setInstanceVariant）への入口を 3 つ持つ: (1) gate 付きアクション行のインライン切替 (2) ドロワー（全 gate 対象の一覧。対象なしなら empty state 明示）(3) 遷移マップ tooltip 内の切替。視線の往復（画面 → 右ペイン → 画面）を消すため

## 不採用の決定

- ログのグルーピング（画面単位折畳み）— 画面名併記のみで様子見
- 埋め込み部品の初期折畳み — 全展開維持
- 画面カードのコマンドパレット化 — マウス探索中心のラフツールに過剰

## Consequences

- simulator.shitae（仕様スケッチ）は本 ADR の全決定へ追随済み
- ADR-0022 の「1. back の trace 追記化」以外のレイアウト・巻き戻し記述、ADR-0023 の描画関連記述を読むときは本 ADR を優先する
